# Учебные источники

Внутренние формулы хранятся в каталогах проекта и проверяются программно. Для трактовки CAGED как переносимых форм, связанных с гаммами и арпеджио, проверены первичные учебные материалы:

- Fender, Intro to the CAGED System: https://www.fender.com/play/guitar/collections/caged-system-major-scales/courses/intro-to-the-caged-system?course-number=2
- JustinGuitar, Chord Shape Explorer: https://www.justinguitar.com/modules/chord-shape-explorer
- JustinGuitar, Fretboard Framework: https://www.justinguitar.com/guitar-lessons/fretboard-framework-mm-010

Дата проверки: 2026-09-18. Тексты интерфейса написаны для GuitarMap самостоятельно; исходные уроки и изображения не копируются.
